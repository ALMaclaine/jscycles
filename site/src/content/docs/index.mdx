## Run it in your repository

<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```sh
    npm install --save-dev jscycles
    npx jscycles
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add --save-dev jscycles
    pnpm exec jscycles
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add --dev jscycles
    yarn jscycles
    ```
  </TabItem>
  <TabItem label="bun">
    ```sh
    bun add --dev jscycles
    bunx jscycles
    ```
  </TabItem>
</Tabs>

On a checkout of [ts-morph](https://github.com/dsherret/ts-morph):

```text title="jscycles packages"
✓ No inter-package cycles

✗ @ts-morph/common: 2 cycles
  src/collections/SortedKeyValueArray.ts -> src/utils/index.ts -> … -> src/collections/SortedKeyValueArray.ts
  src/typescript/index.ts -> src/typescript/tsInternal.ts -> src/typescript/index.ts

✗ ts-morph: 3 cycles
  …
  src/Project.ts -> src/ProjectContext.ts -> src/Project.ts

Summary: 3 packages, 2 with file cycles (5 total), 0 inter-package cycles
```

The exit status is `1`, so a CI step fails until the cycles are fixed.

## Why jscycles

<CardGrid>
  <Card title="File and package cycles" icon="random">
    Loops between files inside each package, and between the packages of an
    npm, yarn, pnpm or bun workspace. One representative loop per tangle, so
    the report is a to-do list rather than thousands of overlapping paths.
  </Card>
  <Card title="Resolves like TypeScript" icon="seti:typescript">
    Path aliases, `extends` chains through `node_modules`, declaration files,
    and `.js` specifiers that point at `.ts` sources. Optionally ignores
    imports that only carry types.
  </Card>
  <Card title="Never a false clean" icon="approve-check">
    Exit status `0` means no cycles, `1` means cycles, `2` means the scan could
    not finish. A file that cannot be parsed fails the scan instead of leaving
    a hole in the graph.
  </Card>
  <Card title="Fast, with no runtime" icon="rocket">
    A single Rust binary that parses with tree-sitter in parallel. Prebuilt for
    Linux (static, Alpine too), macOS and Windows; nothing runs at install
    time, and it never touches the network.
  </Card>
</CardGrid>
